# BlinkIT Outlet & Product Segmentation Analysis

## Project Overview
This project focuses on analyzing BlinkIT grocery outlet data using Python and Machine Learning techniques. The main objective is to identify product performance patterns and segment products based on visibility, sales, and customer ratings using the K-Means Clustering algorithm.

## Objectives
- Analyze grocery outlet and product-related data.
- Perform data cleaning and preprocessing.
- Explore sales and product visibility patterns.
- Apply K-Means Clustering for product segmentation.
- Identify meaningful product groups.
- Generate visualizations to understand clustering results.

## Dataset Description
The dataset contains information about grocery products and outlets, including:

- Item Fat Content
- Item Identifier
- Item Type
- Outlet Establishment Year
- Outlet Identifier
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility
- Sales
- Rating

10. Cluster Interpretation

## Machine Learning Algorithm

**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm used to group similar data points into clusters.

In this project:
- Number of clusters: 5
- Selected features: Item Visibility, Sales, Rating
- Scaling technique: StandardScaler

## Expected Outcomes
- Identification of five product groups based on selected features.
- Understanding of product visibility and sales patterns.
- Identification of high-performing and low-performing product groups.
- Insights to support better retail business decisions.

## Conclusion
This project demonstrates how unsupervised machine learning can be applied to grocery retail data to identify product performance patterns. K-Means clustering helps group similar product records and provides useful insights for retail analysis and business decision-making.
