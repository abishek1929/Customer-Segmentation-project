# Customer Segmentation using K-Means Clustering

## Project Overview
This project performs Customer Segmentation using the K-Means Clustering algorithm in Python (scikit-learn). Customers are grouped based on their Annual Income and Spending Score to identify different customer segments.

## Objective
- Segment customers based on purchasing behavior.
- Analyze customer spending patterns.
- Visualize customer groups using K-Means clustering.

## Technologies Used
- Python 3
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
- Mall_Customers.csv

## Features
- Data preprocessing
- K-Means clustering
- Customer segmentation
- Cluster visualization using scatter plot
- Centroid identification

## Output
The project generates a graph showing different customer segments with colored clusters and cluster centroids.
